## 2. Datos por extremo de barra [REA]
Coeficientes de empotramiento en tres planos por extremo: `coef_empotramiento_xy_inicial/_final`, `coef_empotramiento_xz_inicial/_final` y torsión (`coef_empotramiento_torsion_inicial/_final`, = plano «yz» del diálogo), cada uno con su indicador `con_coef_empotramiento_*` (coeficiente definido, si no hay rigidez rotacional). Valores: **1.0 = empotrado (por defecto, #64632 «Por defecto, el programa asigna a cada barra coeficientes de empotramiento unidad.»)**, 0.0 = articulado; rango 0..1 (#64631 «...coeficientes que pueden tomar valores comprendidos entre '%s' (totalmente articulado) y '%s' (totalmente empotrado), o bien mediante rigideces rotacionales (vinculación interna elástica).»). Aserciones: `coef_empotramiento + 1e-4 > 0`, `fabs(coef_empotramiento_xy_inicial) < PRECISION4` cuando está articulado (coef 0 = articulación). Alternativa «rigidez rotacional» (K, kN·m/rad, `i_rigidez_asignar_t`: `propuesta_por_programa` / `definida_por_usario`, con diagrama momento-curvatura de uniones; pregunta de confirmación si K coincide con el valor por defecto, ver Vinculaciones #65010). Torsión: la entrada es un popup binario 0.000 / 1.000 (`coef_empot`: FALSO «0.000» / CIERTO «1.000», `FUN_18051d550`); xy y xz son campo numérico 0..1 con 3 decimales (paso 0.001). `coef_emp_equivalente > 0`, `coef_emp_parc_giro_nudo1/2` (empotramiento parcial al nudo, vinculación interior #65468-65472, #65085-65091).
Interacción con vinculación interior (#65468-65472): «Nudo empotrado con coeficiente de empotramiento parcial para todas las piezas» (valor en kN·m/rad, [CAP vinculaciones.md]) y la genérica (columna «Empotramiento parcial» #65091 con coeficiente no negativo, 0 = articulación) se combinan con el coeficiente por extremo: el coeficiente de barra (0..1) y el del nudo coexisten [REA, fórmula de combinación NV]. #377915: coeficiente 0..1 incompatible con análisis no lineal [REA, cita previa].
