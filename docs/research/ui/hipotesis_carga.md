# Hipótesis de carga (T-P7-01 y base de T-P7-02)

Origen: sesión RE 2026-11-08. Vías: [REA] = binarios (combs3.dll, combs.dll, catuso.dll, sithipcmb.dll, ghipocal.dll, ed3dlib.dll, e3dcomun.dll; cadenas UTF-16 `<id>texto`, extraídas con el mismo patrón que `tools/extract_dll_strings.py`; combs3.dll no contiene recursos PE ni símbolos, los diálogos se construyen en código y los procedimientos no tienen nombre, así que los textos son la evidencia) y [CAP] = original lanzado y capturado (obra «Obra vacía», normas por defecto Eurocódigo 2, CTE DB SE-A, Código Estructural, CTE DB SE-M, Eurocódigo 9). ## 1. [CAP] Acceso y diálogos

Ruta: Datos generales (o asistente «Obra vacía») > Acciones > **Hipótesis adicionales** (ventana 280x443, icono de libro en el título, `hy_a2`, `orig_carga_hipotesis_adicionales_02`).
- Grupo **Categorías de uso**: texto «No hay categorías de uso definidas» (con categorías: texto de la categoría, p. ej. «A. Domésticos y residenciales») + botón de edición.
- Grupo **Acciones**, columnas **Automáticas | Adicionales**. Filas por orden: Peso propio (auto 1, adicional «---» sin botón), Cargas muertas, Sobrecarga de uso, Temperatura, Retracción, Viento, Sismo, Nieve, Empujes del terreno, Accidental (auto «-», adicionales contador 0 + botón de edición). El contador Adicionales se actualiza con el número de hipótesis adicionales de la naturaleza. Aceptar / Cancelar.
- Cada botón abre una ventana con el **nombre de la naturaleza como título** (304x281, redimensionable y maximizable, `hy_a2`, `hy_e1`): enlace «+ Nueva hipótesis adicional»; tabla con cabeceras **Actúa | Hipótesis adicionales | Editar | Borrar** (Sismo añade **Tipo** entre Hipótesis y Editar, `hy_j_si`); filas alternas blanco/gris con 5 filas vacías; Aceptar / Cancelar. En la ventana pequeña solo se ven parcialmente las columnas y las filas no se repintan (artefacto del original: tras crear «CM 1» la tabla pequeña seguía vacía, pero al maximizar aparece la fila y el contador sube a 1).
- Fila (`hy_e1`): **Actúa** = marca verde por defecto (clic alterna a aspa roja «No actúa», `hy_f1`); celda de hipótesis a dos líneas, **referencia** arriba y **descripción** debajo (sangrada); lápiz (Editar) y aspa roja (Borrar).
- **Borrar** sobre una hipótesis sin cargas: se elimina en el acto, sin pregunta (verificado). Con cargas aplicables las preguntas son [REA] #64905 y #380751/#380752 (ver §2), no vistas.
- **Nueva hipótesis adicional** (415x189, `hy_b1`): **Referencia** (preseleccionada, valor propuesto = prefijo + nº), **Descripción** (vacía), casilla «Con distintas disposiciones de cargas» (desmarcada), Aceptar / Cancelar. Intro actúa como tabulador (Referencia -> Descripción -> Aceptar). Tras crear «CM 1» el siguiente propuesto es «CM 2» (contador por naturaleza, `hy_d2` no conservada; verificado).
- **Con distintas disposiciones** marcada (`hy_i0`, `hy_i2`): la ventana crece; barra con «+» (añadir) y aspa (Borrar, tooltip «Borrar / Suprimir elemento seleccionado de la lista»); tabla **Nombre** con filas «1» y «2» por defecto (el «+» añade «3», «4»..., la nueva queda seleccionada); radios **Compatibles / Incompatibles / Simultáneas**, defecto **Simultáneas**. Tooltip de la casilla: #39163 + #39164. Sismo no tiene esta casilla.
- **Editar hipótesis adicional** (`hy_g1`, mismo formato, icono de libro en el título): Referencia (preseleccionada) + Descripción; sin casilla de disposiciones (no se puede cambiar tras crear).
- **Sismo** > Nueva (`hy_k_si`, icono de libro): Referencia, Descripción y grupo **«Tipo de sismo estático»** con radios **Simple** (defecto) / **XY**; no hay casilla de disposiciones. La ventana Sismo tiene además casilla **«Considerar efectos de segundo orden»** (#46224, desmarcada).
- **Sobrecarga de uso** sin categorías: al abrir sale Aviso «Para poder definir las hipótesis de sobrecarga de uso, primero se deben definir las categorías de uso de la obra.» (#39206, `hy_j_so`), tras Aceptar se abre **Categorías de uso**. Con categoría definida abre la ventana normal «Sobrecarga de uso» (con icono de libro, `hy_m3`).
- **Categorías de uso** (`hy_j_*`/`hy_l1`, `hy_m1`): barra «+», copiar, aspa; tabla **Ref. | Descripción**; Aceptar / Cancelar. «+» abre **Categoría** (`hy_l1`): líneas informativas «Hormigón: Eurocódigo 2 / Cimentación: Eurocódigo 2 / Aluminio: Eurocódigo 9 / Tensiones sobre el terreno: Eurocódigo 2» + combo (defecto «A. Domésticos y residenciales»), y «Acero laminado: Código Estructural / Acero conformado: CTE DB SE-A / Madera: CTE DB SE-M» + combo (defecto «A. Zonas residenciales»); una combo por grupo de normas. La nueva fila: Ref «A», Descripción «A. Domés…».

### Efecto en la pestaña Carga
Ya documentado: combo «Hipótesis» de los diálogos de carga muestra «Peso propio» + hipótesis creadas (p. ej. «CM 1»); «Hipótesis vista» (combo + «Ver todas»). Tras crear una hipótesis con descripción no se vio si el combo muestra la descripción.

## 3. Modelo de datos propuesto
- `LoadNature` enum: SelfWeight (automática única, sin edición), DeadLoad (CM), LiveLoad (Q, requiere categorías), Temperature (T), Shrinkage (R), Wind (V), Seismic (S), Snow (N), EarthPressure (H), Accidental (A); reservadas Frost y FluidWeight (aparecen según normas, no en esta configuración).
- `LoadCase { int id; LoadNature nature; std::string reference; std::string description; bool acts = true; int arrangementCount = 0; ArrangementCompatibility compat = Simultaneous; std::vector<std::string> arrangementNames; SeismicType seismic = Simple; }` — «acts» = columna Actúa; id estable para que las cargas (T-P7-02..05) las referencien.
- `LoadCaseSet`: lista ordenada, siempre con «Peso propio» como caso 0 (no borrable, no editable); contador de propuesta por naturaleza (`nextIndex[nature]`, no se reutiliza al borrar; no verificado si el original reutiliza el hueco); `useCategories` (lista Ref/Descripción + una elección por grupo de normas); `seismicSecondOrder` (bool, solo con Sismo).
- Persistencia JSON en la obra («loadCases»), con deshacer; al borrar un caso: borrar sus cargas y las combinaciones no lineales/de pandeo que lo usan (#64905/#380751/#380752).

## 4. Reglas para la GUI
1. Un diálogo por naturaleza con título = nombre; enlace «Nueva hipótesis adicional»; tabla Actúa/Referencia+Descripción/(Tipo)/Editar/Borrar redimensionable.
2. Referencia propuesta = prefijo + siguiente número; no puede quedar en blanco (aviso «'Referencia' no puede quedar en blanco.»); duplicados: aviso existe en ed3dlib #375648 pero su uso aquí no está verificado.
3. Disposiciones: 2 por defecto, «+»/Borrar, compatibilidad Simultáneas por defecto; no editable tras crear; no existe en Sismo (que tiene Simple/XY).
4. Sobrecarga de uso exige categoría (aviso + abrir Categorías de uso).
5. Borrar sin cargas = inmediato; con cargas, confirmar con #64905.
6. El combo «Hipótesis» de las cargas se alimenta de Peso propio + casos creados.
