# .planning.md – Plan de implementación del clon de CYPE 3D v2027

Estado: **v0.2 (2026-10-31) – stack y alcance aprobados**. Guía maestra del desarrollo. Tareas atómicas en `.tasks.md`, bloqueos en `.tickets.md`, dashboard en `.tasks.html`.
Investigación: `docs/research/01..03_*.md`, capturas en `docs/screenshots/`.

## 1. Evaluación de complejidad (REA + ejecución real)

- CYPE 3D = lanzador de 1 MB + **673 DLL nativas (~1 GB)**, GUI propia (no Qt), OpenGL propio, solver lineal propio (`calcmef`, `calcmallad3d`…) y **OpenSees embebido** (50 MB) para no lineal/pandeo/modal/pushover.
- Alcance funcional: modelador 3D (nudos/barras/pilares/vigas/láminas/paños), 7 pestañas de ribbon con ~120 comandos, cálculo lineal y no lineal, 6+ normas por material, uniones, cimentación, armaduras, sismo, fuego, listados/planos, BIM (IFC, glTF, DXF/DWG), 8 idiomas.
- **Complejidad: muy alta** (equivalente a años-persona del producto original). Estrategia: vertical slices funcionales; cada fase deja un programa ejecutable y verificable contra el original.
- Fidelidad: se replica estructura de interfaz, nombres de comandos, flujos y resultados numéricos (validación cruzada con el original cuando sea posible). Iconos y recursos propios/libres.

## 2. Stack tecnológico — **APROBADO por el usuario el 2026-10-31** (excepto el motor no lineal: ver decisión D2)

Decisiones del usuario:
- **D1:** Stack aprobado tal cual (Qt 6 Widgets + SARibbon + OpenGL propio + Eigen + CMake/vcpkg/CTest + GoogleTest).
- **D2:** Motor no lineal/pandeo/modal/pushover: **embeber OpenSees** (el usuario eligió esta opción tras advertir del riesgo de licencia). Condiciones que me impongo: OpenSees vive en `third_party/OpenSees/` bajo **su propia licencia** (no se relicencia como MIT) con el aviso de copyright de UC Regents íntegro; el programa no se vende; releer el texto de licencia vigente antes de la fase 11 (TK-001). Riesgos técnicos: compilar OpenSees como librería (C++/Fortran, Tcl) con MSVC es costoso → la fase 11 empieza con una spike de viabilidad; si falla, fallback a solver propio (Eigen).
- **D3:** Alcance normativo MVP = preselección del original (EC2, CTE DB SE-A, Código Estructural, CTE DB SE-M, EC9) + EC8 para sismo. Resto → tickets post-MVP.

| Capa | Propuesta | Justificación / verificación |
|---|---|---|
| Lenguaje | C++20, MSVC (VS 2022) | Requisito del proyecto; objetivo Windows x64 |
| Build | CMake + vcpkg (manifest) + CTest | Estándar; `ctest` sustituye a `pytest` del cierre de sesión (proyecto C++) |
| GUI | **Qt 6 (Widgets)**, enlace dinámico | LGPLv3 compatible con distribución portable si se enlaza dinámicamente e incluye licencias. El diseño de "ventana gráfica de estructuras" encaja con QOpenGLWidget |
| Ribbon | **SARibbon** (MIT, Qt 6) | Licencia permisiva verificada en su repositorio; estilo ribbon similar |
| Viewport 3D | `QOpenGLWidget` + OpenGL 4.x propio (picking, snapping, ortho/perspectiva) | El original usa OpenGL propio; control total para selección/edición CAD |
| Álgebra lineal / FEM | **Eigen** (MPL2) + solver propio de pórticos 3D y láminas (MITC4/DKQ) | Sin dependencias restrictivas |
| Motor no lineal/pandeo/modal/pushover | **OpenSees embebido** (decisión D2 del usuario; fallback solver propio con Eigen) | El original también lo embebe. Licencia propia de UC Regents en `third_party/` (no MIT); sin venta; verificación en TK-001 |
| IFC / glTF / DXF | web-ifc o IfcOpenShell (LGPL, a verificar), tinygltf (MIT), libdxfrw (GPL ⇒ **evitar**; alternativa: parser DXF propio o dxflib comprobar licencia) | Licencias a verificar en tarea T-STK-03 |
| PDF/DOCX/HTML | QPdfWriter (Qt), plantillas HTML propias, DOCX vía OOXML mínimo | |
| i18n | Qt Linguist (`.ts/.qm`), código en inglés británico, GUI inicial es-ES | CLAUDE.md |
| Tests | GoogleTest + CTest; capturas comparativas (UI) con script | |
| Distribución | Portable `.zip` (windeployqt) | Rol DEPLOYER |
| Repo | Git/GitHub, licencia MIT | CLAUDE.md |

El solver lineal de pórticos/láminas (fase 8) será propio (Eigen); OpenSees se usa desde la fase 10–11 para pandeo, modal y no lineal.
